# Information Security Policy (ISO/IEC 27001:2022)

This document outlines the security policies, vulnerability reporting processes, and compliance guarantees for the **Maritime Ship Node Mobile Client** (Flutter).

---

## 1. Compliance Baseline
- **ISO/IEC 27001:2022** — Information Security Management Systems.
- **ISO/IEC 25010:2023** — Systems and Software Product Quality (Security & Reliability).
- **Zero-Secret Commit Guarantee**: No private keys, access tokens, or sensitive credentials are committed to version control.

---

## 2. Vulnerability Disclosure Policy

If you discover a security vulnerability within this mobile application:

1. **DO NOT** create a public GitHub issue or discussion.
2. Report the vulnerability privately via email:
   - **Email**: [dafayape@gmail.com](mailto:dafayape@gmail.com)
   - **Subject**: `[SECURITY VULNERABILITY] Maritime Simulation Mobile - <Brief Description>`
3. Include technical details, affected components, steps to reproduce (PoC), and potential impact.
